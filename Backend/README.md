Adaptive Exam System (ระบบทดสอบแบบปรับระดับความยากอัตโนมัติ)
ระบบทำข้อสอบที่ออกแบบมาเพื่อปรับระดับความยากตามความสามารถของผู้สอบ (Adaptive MST) และรองรับการจำลองสอบเสมือนจริง (Mock Exam) ตามโครงสร้างหลักสูตร ก.พ. พร้อมระบบหลังบ้านสำหรับจัดการคลังข้อสอบ

สถานะโปรเจกต์ปัจจุบัน (Project Status)
Backend (Node.js & MySQL): เสร็จสมบูรณ์ 100% (Core API และระบบจัดการไฟล์ภาพพร้อมใช้งาน)

Frontend (React.js): เสร็จสมบูรณ์ 100% (เชื่อมต่อ API, SPA Routing และปรับปรุงระบบ UI/UX เรียบร้อยแล้ว)

ระบบที่พัฒนาเสร็จแล้ว (Completed Features)
1. โหมดฝึกทำข้อสอบ (Practice Mode - Adaptive MST)
ระบบประเมินความสามารถและปรับความยากแบบด่านต่อด่าน (Stage-based) จำนวน 20 ข้อ

POST /api/practice/start: สร้าง Session สำหรับการทำข้อสอบโดยรับค่า user_id และ part_id จากฐานข้อมูลโดยตรง

GET /api/practice/question:

ระบบแบ่งด่านประมวลผลหลังบ้านเป็น 3 ด่าน (Stage 1: ข้อ 1-7, Stage 2: ข้อ 8-14, Stage 3: ข้อ 15-20)

มีระบบ Checkpoint หลังบ้านเพื่อคำนวณและปรับเปลี่ยน Level (1-5) อัตโนมัติตามความแม่นยำของผู้สอบ

การแสดงผลหน้าบ้านทำการซ่อนข้อมูลด่านและระดับความยาก (Clean UI) เพื่อให้ผู้สอบโฟกัสกับโจทย์และลดความกดดัน

POST /api/practice/submit:

ตรวจคำตอบและคำนวณคะแนนแบบถ่วงน้ำหนัก (Weighted Score) โดยให้คะแนนตามระดับความยาก (เช่น Level 3 ได้ 3 แต้ม)

บันทึกสกิลความเก่งล่าสุด (Proficiency Score) ลงตาราง user_skills เมื่อทำครบ 20 ข้อ

ระบบหน้าบ้านจะแอบส่งคำตอบและดึงข้อต่อไปมาแสดงผลทันทีแบบไร้รอยต่อ และกางประวัติการสอบพร้อมเฉลยละเอียด (Explanation) ให้ทบทวนรวดเดียวหลังทำเสร็จ

2. โหมดจำลองสอบ (Mock Exam Mode)
ระบบสุ่มข้อสอบ 100 ข้อ โดยอิงจาก Level ล่าสุดของผู้สอบในแต่ละหมวดวิชา พร้อมระบบจับเวลาถอยหลัง 3 ชั่วโมง

POST /mock/generate:

ดึงข้อมูลทักษะ (Skill) รายวิชาของผู้สอบจากฐานข้อมูลมาเป็นฐานตั้งต้น

สุ่มข้อสอบตามโควตาโครงสร้าง ก.พ. (วิชาความรู้ความสามารถในการคิดวิเคราะห์ 50 ข้อ, วิชาภาษาอังกฤษ 25 ข้อ, วิชาความรู้และลักษณะการเป็นข้าราชการที่ดี 25 ข้อ) พร้อมระบบสลับข้อสอบ (Shuffle)

POST /mock/submit:

บันทึกคะแนนรวมลงในฐานข้อมูลตาราง exam_sessions และปิดสถานะเซสชันเมื่อผู้ใช้กดส่งข้อสอบหรือหมดเวลา

ระบบหน้าบ้าน (Frontend UI/UX):

มีแผงกระดาษคำตอบ (Question Navigator) เลข 1-100 ด้านข้าง สามารถคลิกข้ามข้อ หรือย้อนกลับมาตรวจสอบข้อที่ว่างได้อิสระ

ระบบซ่อนเฉลยระหว่างการสอบ และจะแสดงหน้าสรุปผลคะแนนเมื่อจบการสอบเท่านั้น

มีระบบคัดกรองเฉลยละเอียด (Filter Tabs) ในหน้าทบทวน เพื่อให้ผู้สอบเลือกดูเฉพาะข้อที่ตัวเองตอบผิดได้ทันที

3. ระบบจัดการฐานข้อมูลข้อสอบ (Admin Panel)
ระบบสำหรับผู้ดูแลระบบเพื่อเพิ่มและจัดการคลังข้อสอบ รองรับการนำเข้าข้อมูลแบบ Hybrid (ข้อความและรูปภาพ)

GET /api/admin/parts: ดึงข้อมูลหมวดวิชาและพาร์ทย่อยจากฐานข้อมูลเพื่อแสดงผลใน Dropdown เมนูอัตโนมัติ ป้องกันความผิดพลาดจากการพิมพ์รหัสวิชาแบบ Manual

POST /api/admin/questions: รับข้อมูลข้อสอบใหม่เข้าสู่ฐานข้อมูล รองรับการส่งข้อมูลแบบ multipart/form-data โดยใช้ multer ในการจัดการไฟล์รูปภาพ (บันทึกลงโฟลเดอร์ public/upload/questions/)

ระบบหน้าบ้าน (Frontend UI/UX):

ฟอร์มรองรับการเพิ่มโจทย์หรือตัวเลือกที่เป็นแบบ "ข้อความอย่างเดียว", "รูปภาพอย่างเดียว" หรือ "ทั้งข้อความและรูปภาพ" ได้สูงสุด 5 รูปภาพต่อ 1 ข้อสอบ

มีระบบ Auto-reset อัจฉริยะ ล้างข้อมูลในฟอร์มทันทีเมื่อบันทึกสำเร็จ (แต่คงรหัสวิชาไว้เพื่อความรวดเร็วในการเพิ่มข้อสอบวิชาเดิมอย่างต่อเนื่อง)

โครงสร้างระบบและการจัดการข้อมูล (System Architecture)
การเลือกรายวิชา (Dynamic Selection): หน้าบ้านทำการเรียก API เพื่อดึงข้อมูลหมวดหมู่และพาร์ทย่อยจากตาราง parts มาสร้างเป็น UI โดยอัตโนมัติ ไม่มีการ Hardcode ข้อมูล

การส่งค่าผ่านระบบ: เปลี่ยนไปใช้การส่งค่าและอ้างอิงผ่าน part_id (Integer) ทั้งระบบ เพื่อความแม่นยำในการ Query และป้องกันปัญหาการเข้ารหัสตัวอักษรภาษาไทยเพี้ยน (URL Encoding Error)

การจัดการไฟล์สื่อ (Media Handling): ใช้เทคโนโลยี FormData และ Axios ในการแพ็กข้อมูลฝั่ง Frontend และแกะกล่องประมวลผลฝั่ง Backend ด้วย Multer ทำให้การรับส่งไฟล์ภาพมีความเสถียรสูง

Tech Stack
Backend: Node.js, Express.js, Multer (File Handling)

Database: MySQL

Frontend: React.js (Vite), Axios, HTML5, CSS3
